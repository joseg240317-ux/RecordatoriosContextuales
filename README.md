# Recordatorios Contextuales - Actividad 1

**Estudiante:** Jose Gonzalez  
**Materia:** Programación Mobile  
**Actividad:** 1

Aplicación Android desarrollada en Kotlin con Jetpack Compose y Material 3.

## Requisitos cumplidos

- Proyecto Android con Kotlin, Jetpack Compose y Material 3.
- Modelado inmutable con `data class`.
- Prioridades y estados con `sealed class`.
- Uso de `List`, `Set` y `Map`.
- Categorías sin duplicados.
- Filtrado por estado y prioridad.
- Asociación categoría-color mediante `Map`.
- Reglas de validación.
- Pantalla inicial con recordatorios simulados.
- Pruebas unitarias de validación.

## Ejecución

1. Abrir el proyecto en Android Studio.
2. Esperar la sincronización de Gradle.
3. Usar SDK 35.
4. Crear o seleccionar un emulador desde Device Manager.
5. Ejecutar el módulo `app`.

## Nota sobre Gradle Wrapper

El proyecto incluye `gradle-wrapper.properties`. El archivo binario `gradle-wrapper.jar` no forma parte de esta entrega generada; Android Studio puede sincronizar el proyecto con su configuración local de Gradle o regenerar el wrapper desde un entorno con Gradle instalado.
